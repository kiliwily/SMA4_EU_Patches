# SMA4_EU_Patches
Patches for the european version of SMA4

SMA4_BugFixes: Collection of bug fixes for SMA4 originally from Mario_GMD. Portet for the european version by me.
Credits to: Mario_GMD.

SMA4_Improvements: Collection of bug fixes and improvements for SMA4 from me.

SMA4_e-Deluxe: Patch originally from Mode8fx that adds all Power-Up and Demo cards into the game in a similar way the Virtual Console and Switch Online version added all the Level cards. Converted and code and data repointed (to prevent the rom from expanding from 8 to 16 MB upon patching) by me with the help of caude ai.
Credits to: Mode8fx.

SMA4_BugFixes compatible with all 3 of the following roms. SMA4_Improvements is also compatible with all 3 roms, but some of the features of the patch will only work in the Virtual Console and the Switch Online version. SMA4_e-Deluxe is only compatible with the  Virtual Console and the Switch Online version.
